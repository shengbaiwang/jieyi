# PDF 可读排版与安全回填（2026-10-31）

## 问题与根因

诗歌教材物理第 17 页的白色逐行底纹被当作图片障碍，触发整页重排。随后旧的跨区排版把首个窄区域产生的软换行写回剩余正文，后续宽区无法恢复正常行宽，最终将整页缩成窄小文字。

本次修改的是所有 PDF 预览和导出共用的 `compose_pdf`，没有针对书名、文档 ID、页码或具体译文设置例外。

## 持续生效的规则

- 文本流保存原字符偏移及每字字体归属。换区时按新的宽度重新折行；显式换行与空行保留。共享文字对象回填支持拉丁重音、希腊、俄语、韩语等词间空格，不把源文本分裂出的 G/ulf 错拼成两个词。
- 底纹需符合绘制顺序、字形归属、轴对齐矩形、不透明颜色及文字覆盖条件；支持浅彩色多行说明框，以及被源亮色文字充分拥有的深色标题框。字号判断使用原生字号和对象矩阵，避免把大写字母墨迹高度误作整行字号。父底纹中无早期文字遮挡的同色子条带保留为整体底纹。所有原图片、路径、底纹保留；前景遮罩、图片上的白板、未经确认的彩色图形和半透明图形仍受保护。
- 底纹条带的精度容差有限：同色子条带仅容许 0.3pt 的父框偏差；更宽的顶部/底部填充必须由两侧真实、同色窄边框确认，左右外扩各不超过 1.5pt，条带高度不超过 24pt 或父框高度的一半。边框继续作为障碍；无边框溢出、前景覆盖与底层插图不因此放行。
- 独立绘制的窄空格底纹仅在左右底纹已分别验证、同色同高且边缘精确贴合时，才能作为连接条带。连接宽度必须同时不超过条带高度的 50% 与 0.6em；保留原路径，不能借此放行前景遮罩或未经确认的图形。此通用规则修复了真实第 72 页的单独空格底纹，已有 8 项正反回归覆盖。
- 识别由源文字拥有的细下划线，保留原路径；正文中部的黑色细条不能冒充下划线。
- 已确认的说明框提供可用宽度和边界；排版、扩展及回退都受容器边界约束，不借用框外正文空间。分组增长先按容器归属隔离，避免先合并框外正文再被边界检查误拒绝。重排只合并连续、对齐、字号接近且同类的段落；不跨越标题、多栏间隙或图形。原文对象需要完整归属，不能只删部分原文后继续叠加译文。
- 旋转页统一在原生坐标中核对字形、字号和绘制区域，防止把旋转字宽误作字号。源文字主色及跨段落回退中的每字颜色、字体归属随文本流保留，深色框中的白字不改为黑字。
- 正文缩字号下限为 `min(原字号, max(8pt, 原字号×70%))`；原本小于 8pt 的脚注保留其原字号。放不下时不再降至微小字号或遗漏字符。
- 目录点线作为弹性间距处理。源文件中被白遮罩修订的页码保留原生数字和遮罩，只替换左侧标签；页码不一致、对象不能分离或条目无法安全容纳时拒绝重排，防止重复页码。已固定的目录条目不能被邻接正文的回退分组吞并，最终复查仍禁止移动页码。
- 提取器将“目录行 + 后续标题”合成一段时，仅在源文与译文均明确包含前导点线、相同页码和非空后缀，且原区域恰为两条不重叠物理行时，尝试临时拆计划。两行原生字形按横坐标排序后，必须分别与源前缀、后缀精确对应；拆分保留文字和原段 ID，目录行继续保护原生数字及遮罩。归属不明、页码变化或无法容纳时明确拒绝，不修改数据库。
- 单行标题仅在原墨迹确实位于底部边线之上、原字号不变且实际译文字形需要避让时，允许向上移动 baseline，最多 0.3em。移动后的字形与绘制区域均须通过页面、容器、相邻原文和已有译文碰撞复查；不绕过真实边框。多行、旋转、行中插图、表格内部横线、超过上移限度或会撞到上方内容的情况不适用。
- 返回前复查每个译文区域与剩余原文及图形的碰撞。不能安全输出时返回 HTTP 422，阅读器在原页面展示具体原因与重试入口。跨表格线的整行段落提示调整段落结构，不误导为单纯缩短译文。

`PDF_LAYOUT_VERSION = "safe-flow-v3"` 纳入预览缓存版本，后续规则变更需同步升级，防止复用旧图。几何迁移机制仍由 `GEOMETRY_VERSION` 管理，不重译或改写现有译文。

## 原安全模式的边界（导出行为已由下文 direct-flow-v4 替代）

任意 PDF 的字体、嵌套 Form、扫描文字、公式和表格没有统一可靠的语义结构，不能以回归测试替代全部真实文件验收。本次对已支持的原生文字路径完成通用修复，并对无法确认的结构拒绝生成错误版面。

真实教材已目视确认的结构阻断为物理第 153–155、158–159、161–174、236 页，共 20 页，涉及真实多栏表格、音步表格或左右对照表。旧导入合并了单元格，部分符号、词序也已缺失；需要先恢复单元格、符号及文字归属，再由原位编辑/审校修订相应译文。不能猜测中文字符比例后分配到格子，也不能将这些页记为排版成功。排版修复不会静默重译或覆盖用户已有译文。

## 追加：窄章节标记误拒（safe-flow-v2）

《Thirteen Months in China》物理第 43 页的原文和译文都是单个章节罗马数字 `I`：原字号 16pt，原文字框宽 4.448pt，替换字体中的字形实际宽 3.616pt，原字号完全放得下。旧 `_fit` 却要求区域宽度至少为一个字号（16pt），把窄字符误判为容量不足，错误地提示缩短译文。这不是表格结构问题，也不需要用户修改该译文。

已移除整 em 宽度前置条件，改为检查区域宽度为正、再由现有逐字符字体字宽量测确认是否完整容纳；真实超宽字、多行、无效区域及可读字号下限仍受检查。原生 I/II 章节标记、每字字体归属、宽字与多行反例共 8 项新增测试通过；全部 PDF 与字体相关测试共 171 项通过，Ruff 通过。第 43 页真实离线合成成功，10 段替换、无回退、无溢出，译文页已目视复验。safe-flow-v2 的实际接口第 43 页返回 200；随后整书检查又发现了下述两类边界问题，已继续修复。

## 2026-10-31：直接导出与性能优化（direct-flow-v4）

按用户要求，书籍导出和译页预览不再因表格线、图形碰撞、段落映射或可读字号检查中断。优先沿用现有原位排版；遇到这些排版约束时，仅将相关页切换为按原区域完整写入文字并缩放适配。图形不删、不覆盖遮罩，不增加续页，不修改数据库里的译文。保守模式仅供内部诊断与回归测试使用，没有新增用户设置或确认步骤。

直接适配可缩小到原安全模式的字号下限以下；本次真实文档最小约 2.86pt。旧导入合并单元格的问题没有因此获得语义修复，表格中的译文仍可能跨格或很小。`direct_pages` 记录采用此策略的页码，不能将导出成功视为全书表格结构验收。

性能改动：缓存每页原生对象键和字形边界；只为原框放不下的段落测量扩展空间，测量仍基于未修改的原页；全书使用一个多页 Canvas 共享字体子集，省去第二次整书克隆；API 提供最多 64 MiB / 4 份的进程内 LRU 缓存并合并相同内容的并发请求。缓存指纹包含源 PDF、布局、有效译文、源文、段落删除、双语模式与字体配置，编辑后不会复用旧译本。
