# 术语语境核验：实施与验证

2026-09-02，质量检测器版本 6，语境核验协议版本 1。

## 已实施的行为

批准术语表示批准该义项的译法，不表示这个词在全书只有一个义项。术语范围使用
`enforcement=global|contextual|auto`：新候选批准及手工添加界面默认按语境生效；旧数据
使用 auto，只要有义项、消歧说明或语境关键词就按语境处理。用户明确声明 global 的
固定译法继续进入严格检查。关键词只作为提示，不自动证明词义。

`terminology.py` 是生成提示、批准回查和确定性 QA 的共同入口。匹配保留原文字符位置，
已批准的长词组覆盖其内部短词；同段其他位置的短词仍独立处理。条件提示包含完整义项、
消歧说明、禁用译法和具体出现位置，并明确允许词库之外的义项不适用。

条件术语的未核验项使用 info / terminology_pending，独立显示于审校页。它们不进入
人工必检，也不能进入“已审校且干净”的分布抽检。单纯把 error 降成 warning 不足以
修复原问题，因此人工队列现在使用 requires_human 属性。

## 机器核验与证据

批准后只完成本地回查并登记待核验状态。用户在审校页点击“开始语境核验”才发送模型
请求；页面显示所选模型及服务主机。优先使用配置中的审校模型，未配置时使用草译模型。

核验独立于翻译任务，不修改书稿、术语批准状态或人工决定。每个出现位置输出：

- not_applicable：本次用法不属于批准义项；
- consistent：对应译法一致；
- inconsistent：适用义项下疑似译法错误，作为模型建议交人工复核；
- uncertain：模型仍无法确定，交人工判断；
- 没有有效结果：继续待机器核验，绝不当成通过。

程序校验返回 ID、原文引文必须覆盖对应出现位置、译文引文必须真实存在。模型可返回
精确引文而不计算字符偏移，由程序定位；重复译文引文要求明确指定第几个。确实漏译时
可以报告空译文引文，但只能成为疑似不一致，不能成为确定错误。同位置多个竞争义项都
被判为适用时，统一转成人工判断。书目是否保留原文由项目规则和上下文判断，不按章节名
直接豁免。

任务保存在 terminology_review_runs，证据保存在 terminology_verdicts。缓存绑定原文、
当前可见译文、完整词库、项目风格/引文规则和核验协议版本；保存模型与运行来源。原译文
或词库变化后，过期结果仍留在历史中，但不参与当前通过/告警统计。当前实现保守地重做
整项核验，没有单独复用源文判义缓存。

请求每批最多 4 处，同时最多 2 个模型调用，单次超时 180 秒。缺答或无效证据最多重试
一次；持续无效会提前停止。本轮默认 token 预算 200,000，API 上限 2,000,000；每次请求
前按保守输入字节上限和输出预留判断预算。token、费用及结果数量单独记录。失败、预算
耗尽和进程中断都保留已完成结果，用户可以继续剩余项。服务启动不会自行外发数据。

API：GET /documents/{id}/terminology-review 查看状态，POST 同一路径启动后台核验。
POST 接受 token_budget。GET /documents/{id}/issues 返回有效语境证据与本地规则的统一
视图。语境模型结果不改变 overview.reviewed_count，它不是全书独立审校。

## 数据迁移

检测器版本变化会重算已有译文。重算只替换本检测器的规则代码，不清除 reviewer_attention、
translation_deferred 等其他来源。旧规则记录保留为已被新快照替代，不设置人工确认。
没有历史规则问题且检查通过的段落不打开写事务；共享术语和任务上下文按文档读取一次。

在真实数据库副本上验证了 11,531 个已译段落的重算，所有 segments 字段的整体哈希前后
一致。优化后强制重算约 1.5 秒。目标书的 94 个旧术语错误变成 247 段、307 处待核验，
第 1529 段原有翻译失败仍保留。307 处包括当前译文已有“国家”的位置，避免遗漏错位问题。

## 验证与限制

tests/test_terminology_review.py 覆盖状态义、行政区划、动词、复合词、关键词干扰、
同段不同义项、真正不一致、对应译文位置、Unicode 原文位置、引文校验、缓存失效、
竞争义项矛盾、预算/失败/重试、旧模式迁移、其他来源问题和人工决定保留。现有 API、
翻译工作流、候选批准测试也更新到新契约。

本地完整后端测试、前端构建和服务端渲染测试已通过。语境核验使用可控的模型适配器测试，
不等同于真实模型的判义准确率评估。实际外部模型试跑被自动审批拒绝，原因是尚未获得
向配置服务发送原译文的明确许可；没有绕过此限制。真实模型精确率、漏报率和费用基准
需要获准后用人工标注语料继续评估，不能将“告警数下降”宣称为准确率提升。
