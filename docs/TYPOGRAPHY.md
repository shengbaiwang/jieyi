# 译文字体层次

译文沿用原文的字体角色：衬线正文使用宋体族，无衬线内容使用黑体族，斜体强调优先使用楷体，粗体保留字重。字体由本地规则确定，不交给翻译模型重新设计。字号、段落和原有版面仍由各格式的排版流程处理。

## EPUB

- 根据当前章节链接的 CSS、导入样式和行内样式解析字体继承，处理字体简写、声明顺序与 `!important`，沿用现有标签、类、ID、后代选择器的匹配能力；不是完整浏览器 CSS 计算器。
- 只为中文目标语言添加字体回退。原书西文字体放在中文回退字体之前，泛型字体放在最后。
- 行内强调、粗体及字体变化随受保护的内联标记回填；双语译栏按包装前的原文上下文匹配字体规则。中文强调以本地楷体别名承接斜体，西文继续保留斜体；缺少楷体时保留可见的斜体回退。
- 阅读预览、仅译文 EPUB 与双语 EPUB 使用同一套映射。原文栏、原版模式、SVG、数学内容和插图不添加字体覆盖。字体回退不要求重新翻译已有文本。
- 若历史译文已经丢失内联标记，无法仅凭两种语言的字符位置可靠恢复某个词的强调范围；本实现不会猜测对应位置。

## PDF

导入时保存每个文字区的主要源字体。老文档按已有行框从原始 PDF 补取字体，不改变段落、ID 或译文。预览和导出共用字体选择、字体度量、换行与绘制；整页重排仍保留各段字体。字体规则版本进入译文预览缓存键。

字体优先使用可嵌入的本机字体。宋体、黑体和楷体各自有候选路径，macOS 也可使用用户字体目录里已安装的楷体；无楷体时使用可用的不同字形回退。可单独指定：

- `JIEYI_PDF_FONT_SERIF` / `JIEYI_PDF_FONT_SERIF_BOLD`
- `JIEYI_PDF_FONT_SANS` / `JIEYI_PDF_FONT_SANS_BOLD`
- `JIEYI_PDF_FONT_KAI` / `JIEYI_PDF_FONT_KAI_BOLD`
- `JIEYI_PDF_FONT_MONO` / `JIEYI_PDF_FONT_MONO_BOLD`

`JIEYI_PDF_FONT` 仍可统一指定字体。指定文件需包含译文所需字符；不同角色能否呈现不同字形，取决于本机字体和显式配置。字体子集随译文 PDF 嵌入，不向项目复制用户字体文件。

目前 PDF 映射粒度为文字区/段落。段内个别词的混合字体尚未绑定到译文的语义范围；单凭原文字框不能可靠推算跨语言对应位置，因此没有按字符比例硬套样式。

## 验证

`tests/test_typography.py` 覆盖字体族识别、继承与强调恢复、CSS 优先级、双语与仅译文一致、原文和插图隔离、非中文目标语言、老 PDF 补全、长译文重排中的字体保留以及预览/导出像素一致。
